# Sistema de Controle Financeiro Pessoal

## Status do projeto
Em desenvolvimento

## Tecnologias utilizadas
- Java
- Java Swing
- MySQL
- JDBC
- Git e GitHub

## Time de desenvolvedores
- Luis Claudio

## Objetivo do software
O sistema tem como objetivo auxiliar no controle financeiro pessoal, permitindo o cadastro e gerenciamento de usuários, registros de receitas e despesas, possibilitando uma melhor organização financeira.

## Funcionalidades do sistema
- Cadastro e autenticação de usuários
- Controle de permissões por usuário
- Cadastro de transações financeiras (receitas e despesas)
- Listagem de movimentações financeiras
- Associação das transações ao usuário logado
- Interface gráfica desktop utilizando Java Swing
- Persistência de dados em banco de dados MySQL
